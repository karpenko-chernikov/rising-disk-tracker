# Трекер поднимающегося диска

Программа для команды **Бобры**: печать меток на диск, обработка видео эксперимента, Excel, графики и видео с треком.

Сняли ролик → положили во `входящие/` → одна команда → готовые результаты в `прогоны/`.

---

## Что нужно установить (один раз)

### 1. Программы на компьютере

- **Python 3.10+** ([python.org](https://www.python.org/downloads/) или через Homebrew: `brew install python`)
- **Git** (чтобы скачать репозиторий)
- Для просмотра PDF меток — любой просмотрщик PDF
- Принтер (печать меток **в масштабе 100%**)

### 2. Скачать проект

```bash
git clone https://github.com/karpenko-chernikov/rising-disk-tracker.git
cd rising-disk-tracker
```

(если адрес репозитория другой — подставьте свой)

### 3. Виртуальное окружение и библиотеки

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r требования.txt
chmod +x трекер.sh                 # macOS / Linux
```

Проверка:

```bash
./трекер.sh --help
```

Должны появиться команды `метки` и `обработать`.

### 4. Настройка установки (один раз)

Откройте файл `настройки/установка.yaml` и укажите:

```yaml
радиус_ведущего_колеса_мм: 15   # измерьте штангенциркулем жёлтое ведущее колесо
установка: бобры1
```

Это нужно, чтобы из об/мин в имени файла посчитать линейную скорость привода \(W\).

## Порядок действий экспериментатора

### А. Один раз на каждый физический диск (метки)

1. Запустите:

```bash
source .venv/bin/activate
./трекер.sh метки
```

2. Введите по запросу:
   - **радиус диска** в мм (для диска Ø 10 см → **50**);
   - **массу** в граммах;
   - **ID диска** (например `бобры-01`) или Enter для авто.

   Без вопросов:

```bash
./трекер.sh метки --R-мм 50 --масса-г 50 --id бобры-01 --no-интерактив
```

3. Откройте PDF из `калибровка/наклейки/` (файл `метки_….pdf`).

4. **Печать:** масштаб **100%**, не «вписать в страницу».

5. Линейкой проверьте: сторона квадрата ≈ число из инструкции в PDF (для Ø10 см обычно **10 мм**).

6. Вырежьте **три** квадрата (ID 0, 1, 2) и наклейте на **лицо диска** по схеме на 2-й странице PDF:
   - сторона, которую снимает камера (**справа** от установки);
   - **вне** зоны, где жмёт ролик (центр не клеить);
   - точность позиции ±2–3 мм нормальна; важнее правильный размер печати.

Масса и радиус сохраняются в `раскладка_….yaml` (внутри самих ArUco их нет).

---

### Б. Каждый опыт (съёмка и обработка)

1. Камера **справа**, перпендикулярно лицу диска; диск крупно в кадре; штатив не двигать.
2. Выставьте привод и смещение оси, запомните:
   - \(n\) — **об/мин ведущего колеса**;
   - \(\delta\) — смещение в **мм** со знаком (например −10).
3. Снимите один ролик (желательно 60–240 fps, короткая выдержка).
4. Скопируйте файл в папку **`входящие/`**.
5. Назовите файл так:

```text
n120_d-10.mov
```

| Часть | Смысл | Пример |
|-------|--------|--------|
| `n120` | об/мин ведущего колеса | `n85`, `n120` |
| `d-10` | δ в мм со знаком | `d12`, `d-5` |

Можно добавить префикс: `опыт3_n120_d-10.mp4`.

6. Запустите обработку:

```bash
source .venv/bin/activate
./трекер.sh обработать
```

7. Смотрите результат:

```text
прогоны/<дата съёмки>/
  сводка.xlsx              — все ролики дня + лист «словарь»
  сводка.html              — удобная таблица в браузере
  карта_режимов.png        — n–δ, цвет = σ(Ω)
  ролики/<имя файла>/
    отчёт.txt              — ПОДРОБНО: что значит каждое число
    ряд_по_времени.xlsx    — кадры + лист «словарь» с пояснениями
    графики/               — траектория, фазы, спектр, Пуанкарé, модель…
    наложения/трек_хвост.mp4
    наложения/трек_полный.mp4
    мета.json
```

**С чего начать человеку:** откройте `отчёт.txt` — там объясняется каждый параметр.  
В Excel на листе **«словарь»** — смысл каждой колонки.

Исходное видео после успеха → **`обработанные/`** (сырьё).  
Цифры и картинки → **`прогоны/`** (результаты).  
При ошибке → **`ошибки/`** (+ `….ошибка.txt`).

## Папки проекта

| Папка | Что делать |
|-------|------------|
| `входящие/` | сюда кладёте сырые ролики |
| `обработанные/` | сюда программа переносит успешные |
| `ошибки/` | сбои |
| `прогоны/` | все результаты |
| `калибровка/наклейки/` | PDF меток и yaml |
| `настройки/` | параметры установки и разметки |

## Быстрая проверка без камеры (опционально)

Убедиться, что всё установилось:

```bash
source .venv/bin/activate
./трекер.sh метки --R-мм 50 --масса-г 50 --id тест --no-интерактив
PYTHONPATH=исходники python -m трекер.синтетика
./трекер.sh обработать
```

Должна появиться папка в `прогоны/` с графиками, `трек_хвост.mp4` / `трек_полный.mp4` и подробным `отчёт.txt`. На синтетике \(\Omega \approx 1.2\) рад/с.

## Частые проблемы

| Проблема | Что сделать |
|----------|-------------|
| `./трекер.sh: Permission denied` | `chmod +x трекер.sh` |
| Нет модуля / ImportError | `source .venv/bin/activate` и снова `pip install -r требования.txt` |
| Мало кадров с треком | свет, фокус, метки крупнее в кадре, печать 100%, камера справа |
| Нет `раскладка_текущая.yaml` | сначала выполните `./трекер.sh метки` |
| W странный | проверьте `радиус_ведущего_колеса_мм` в `настройки/установка.yaml` |
